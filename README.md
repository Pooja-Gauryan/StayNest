# 🏠 StayNest – Find Your Perfect Student Home

StayNest is a Full Stack Web Application developed to simplify the process of finding and managing student accommodations such as PGs, Hostels, Flats, and Rental Rooms.

The platform allows students to discover suitable accommodations while enabling property owners to securely publish and manage their property listings through a personalized dashboard.
